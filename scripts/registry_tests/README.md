# Registry Tests

Standalone validation scripts (Python and Node.js) for testing API integrations with individual IPO registrars and exchanges.

Used to verify logic, parsing, and connectivity before adding them to the main React Native app. Includes tests for:
- BSE / NSE
- Alankit
- Bigshare
- KFintech (and KPrism)
- Purva Sharegistry
- Skyline Financial Services
